▶ ARQUITECTURA ESTÁTICA ◀
¿Cómo funcionaba la Web 1.0?

En los años 90, la web era completamente estática. El servidor guardaba archivos .html en el disco. Cuando el usuario hacía una petición HTTP, el servidor los enviaba tal cual. No había base de datos, no había lógica del servidor, no había JavaScript dinámico. Cada página era un archivo físico en el servidor.

Tecnologías de la época:

✦ HTML 1.0 / 2.0 — Sin CSS, sin JS dinámico
✦ GIF animados como único elemento "dinámico"
✦ Formularios básicos enviados por GET/POST
✦ Protocolo HTTP/1.0 — una conexión por recurso
✦ Hosting en servidores FTP compartidos
✦ Sin estado (stateless) — sin cookies, sin sesiones

⚙ Arquitectura Dinámica: AJAX + PHP + MySQL

Por Juan Dev | 15 de Marzo, 2006 | PHP, Ajax

La Web 2.0 revolucionó la arquitectura web al introducir lógica en el servidor. Ya no servíamos archivos estáticos: ahora el servidor ejecutaba código PHP que consultaba una base de datos MySQL y generaba HTML dinámico a partir de los datos.

⇄

⚙
Apache + PHP
⇄

🗄
MySQL

La revolución real fue AJAX (Asynchronous JavaScript and XML). Con esta técnica, el navegador podía pedir datos al servidor sin recargar la página completa. Gmail lo popularizó en 2004.

ejemplo_ajax.php — Código típico del 2006 
<?php
  // Conectar a la base de datos
  $conn = mysql_connect("localhost", "root", "");
  mysql_select_db("mi_blog", $conn);

  // Consultar entradas del blog
  $result = mysql_query(
    "SELECT * FROM posts ORDER BY fecha DESC"
  );

  while ($row = mysql_fetch_array($result)) {
    echo "<div class='post'>"
       . $row['titulo']
       . "</div>";
  }
?>

// JavaScript: XMLHttpRequest (pre-jQuery)
var xhr = new XMLHttpRequest();
xhr.open('GET', 'data.php?id=1', true);
xhr.onreadystatechange = function() {
  if (xhr.readyState === 4 && xhr.status === 200) {
    document.getElementById('content')
            .innerHTML = xhr.responseText;
  }
};
xhr.send();
